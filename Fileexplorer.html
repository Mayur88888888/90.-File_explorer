✨ Features

  • Recursive folder scan — walks all child folders, reads real files & sizes
  • Dynamic format detection — every extension found becomes a filter chip
  • Multi-filter search — combine category, size, format & free-text search
  • Folder analysis — see which sub-folders take the most space
  • Locate on disk — copy any file's full path with one click
  • 5 themes — Dark, Light, Nord, Solarized, High Contrast
  • Sortable columns — name, category, size, date, type

🔒 Privacy & Offline

✅ 100% offline ✅ No uploads ✅ No tracking ✅ No CDN / libraries ✅ Runs from a single HTML file
  • All scanning happens in your browser — files never leave your machine.
  • No analytics, no telemetry, no network calls of any kind.
  • Only your theme preference is saved locally in localStorage.

🌐 Browser Support

  • Chrome / Edge / Brave / Opera — full folder scanning
  • Firefox / Safari — app loads, but folder picker needs drag & drop
